# Competitive analysis (partial, reviewed 2026-10-22)
**Status: incomplete.** Only iLovePDF was researched this session, and only through third-party review and listing sites, not its official pages. Smallpdf, PDF24, Adobe Acrobat, PDF.js and pdf-lib were **not** researched here. Nothing below is verified against official sources, and no figure should be quoted without checking the vendor's own pricing and help pages.

## iLovePDF (secondary sources only)
- Web tools for merging, splitting, compressing, converting and editing PDFs, with free and paid tiers (sources: Capterra listings, GetApp, Fitgap, Temperstack).
- Reviewers repeatedly report free-tier limits on file size and daily tasks. One summary site cites a 40 MB free cap and another a 3-task daily limit; these differ and are unverified.
- A desktop app is listed from about $6.61/month (GetApp/Capterra). Unverified.
- Reviewers say files on the web tool go to the vendor's servers, and some advise against using it for sensitive bank or legal documents. This is reviewer opinion, not a policy statement.

## Where this app differs (design facts about this project)
- Files never leave the browser; no accounts, quotas or file-size caps beyond browser memory.
- Accounting workflow: document types, presets, month-based names, index page, page numbers, blank-page review.
- Weaker than the commercial tools: no layout-preserving Word/Excel/PowerPoint conversion, no Office-to-PDF, no PDF text editing, no certificate signatures.
